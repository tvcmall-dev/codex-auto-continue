# v0.2.1-preview · 会话状态显示改进

本版改进“执行中”会话的显示，并修复时间精度差异造成的状态更新延迟。适用于 Windows 10/11 x64，需要 .NET Framework 4.8。

## 本版变化

- 主面板启动后默认显示“执行中”，可切换“全部”或“需关注”查看其他会话。
- 修复轮次开始时间精确到秒、同轮用户消息精确到毫秒时，开始事件被误当作旧事件过滤的问题；新轮次可在下一次轮询显示“执行中”，无需等待首条输出。
- 详情面板复用本轮会话快照，并合并重复界面刷新，减少历史事件较多时的卡顿。
- 首次读取时，同一轮次仍为 `inProgress`，且最近 2 分钟内有真实输出或已完成工具执行的会话，可立即显示“执行中”。这只提供近期活动的显示线索，不确认自动续接成功，也不触发历史失败重试。
- 单独的轮次开始记录、未完成工具调用或历史 `inProgress` 状态不足以证明仍在执行；超过 2 分钟没有新执行证据时，仍会转为待确认。
- README 与便携说明使用功能描述，保留运行要求和真实接入限制。

## 下载与升级

[便携 ZIP](https://github.com/tvcmall-dev/codex-auto-continue/releases/download/v0.2.1-preview/CodexAutoContinue-0.2.1-preview-win-x64.zip) · [单独 EXE](https://github.com/tvcmall-dev/codex-auto-continue/releases/download/v0.2.1-preview/CodexAutoContinue.exe) · [SHA-256 清单](https://github.com/tvcmall-dev/codex-auto-continue/releases/download/v0.2.1-preview/SHA256SUMS.txt)

**0.1.0-preview 用户需要先手动安装当前版本一次。** 从托盘退出旧程序，下载本版便携包或 EXE，核对 SHA-256 后覆盖原目录。0.2.0-preview 用户可通过“设置 → 应用升级”检查并安装本版。设置、Webhook 配置与监控记录保留在原用户数据目录。

自动升级方式保持不变：启动时及每 6 小时检查固定的 `tvcmall-dev/codex-auto-continue` GitHub Releases，自动下载并校验 SHA-256、文件大小与程序版本，空闲时重启安装。设置编辑、消息发送、通知投递、Webhook 测试及仍启用的待续接计划都会延迟安装。新进程需在 20 秒内通过启动检查，否则尝试从 `CodexAutoContinue.exe.previous` 回退；失败版本进入 24 小时自动升级冷却期。可在设置中关闭自动检查、自动安装或预览版更新。

## 接入限制

当前已验证真实 Codex 桌面会话读取，仍未找到当前 Windows Codex 桌面端可供外部连接的已验证恢复控制端点。CLI 入队或返回退出码 0 均不代表任务已恢复；程序保持待确认，需观察实际执行证据。首次读取时的“执行中”显示线索不会放宽这一确认要求，本版仍不能保证无人值守续跑。

完整步骤、状态规则与故障恢复见[使用说明](../使用说明.md)。
