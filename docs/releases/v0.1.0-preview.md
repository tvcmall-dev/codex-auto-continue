# v0.1.0-preview · Windows WPF 测试版

首个可运行的原生 Windows 测试版，支持 Windows 10/11 x64 与 .NET Framework 4.8，无需 Node.js、Python 或单独的 API Key。

**已验证真实桌面会话读取，尚未验证当前 Codex 桌面端的任务自动恢复。** 当前桌面后端以 stdio 运行，未找到可连接的现有控制端点；`queue --resume` 可能无法触发桌面执行。程序会保留待确认状态，绝不把 CLI 入队当作恢复成功。本版本不保证无人值守续跑。

## 功能

- 原生 WPF 暗黑面板、会话搜索筛选、状态矢量插画、事件记录与系统托盘。
- 最近 120 个本机桌面主会话的只读事件监测，单会话默认关闭、可分别开启。
- 新确认网络或临时服务故障后的有限续接策略、发送前状态重查、防重复与重启核对。
- 中文 `继续`、英文 `continue` 或自定义消息，保存后统一用于手动与自动续接。
- 钉钉、飞书、企业微信、通用 Webhook，支持签名、真实手动测试及最多 3 次独立投递。
- SQLite 持久化、Windows 当前用户 DPAPI 保护完整 Webhook URL 和密钥。
