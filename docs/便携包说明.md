# Codex 续航 · Windows 便携测试版

版本 `0.2.0-preview`，适用于 Windows 10/11 x64，需要 .NET Framework 4.8。

双击 `CodexAutoContinue.exe` 运行，无需安装或管理员权限。完整操作步骤见同目录的[使用说明](使用说明.md)。`SHA256SUMS.txt` 提供 EXE 的 SHA-256 校验值。

程序提供原生 WPF 暗黑面板、真实本地会话读取、异常续接策略、中文/英文/自定义消息、托盘、Webhook 通知与自动升级。单会话监控默认关闭，需在面板中逐个开启。

**0.1.0-preview 用户需要先手动升级一次。** 从托盘退出旧程序后，用本包覆盖原程序目录即可；设置和监控记录保存在 `%LOCALAPPDATA%\CodexAutoContinue`，升级不会替换这些数据。

本版本默认在启动时和此后每 6 小时检查固定的 `tvcmall-dev/codex-auto-continue` GitHub Releases，发现新版本后自动下载、校验 SHA-256，再于本程序空闲时重启安装。打开设置、刷新、发送消息、投递通知或测试 Webhook 时会等待；已启用监控的待续接计划即使尚未到执行时间，也会延迟安装。

新版本需在 20 秒内通过启动检查，否则尝试回退上一版本；替换时备份为原目录中的 `CodexAutoContinue.exe.previous`。失败版本进入 24 小时自动升级冷却期。请保留程序名 `CodexAutoContinue.exe`，并把程序放在当前用户可写的目录；自动升级不请求管理员权限。“设置 → 应用升级”可关闭自动检查、自动安装或预览版更新，也可手动检查与安装。

**当前为预览测试版。** 本机已验证真实会话读取，但当前 Codex 桌面端没有暴露已验证的控制端点，尚未验证自动恢复任务成功。CLI 入队后会保持“待确认”，只有后续真实执行证据才会确认恢复，不能保证无人值守续跑。

源码与构建脚本：[GitHub 项目](https://github.com/tvcmall-dev/codex-auto-continue)。本版下载与校验值：[v0.2.0-preview 发布页](https://github.com/tvcmall-dev/codex-auto-continue/releases/tag/v0.2.0-preview)。
