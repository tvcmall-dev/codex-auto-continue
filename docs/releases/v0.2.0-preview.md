# v0.2.0-preview · 自动升级测试版

本版为 Windows WPF 桌面程序加入自动升级：发现新版本后自动下载，程序空闲时自动重启安装。适用于 Windows 10/11 x64 与 .NET Framework 4.8。

**0.1.0-preview 没有自动升级能力，需要手动安装本版一次。** 从托盘退出旧程序，下载本版便携包或 EXE，核对 SHA-256 后覆盖原程序目录。设置、Webhook 配置与监控记录继续保存在原用户数据目录。

## 新增功能

- “设置 → 应用升级”展示当前版本、可用版本、下载进度及状态，提供“立即检查更新”和“保存设置并重启安装”。
- 默认启动时及每 6 小时检查固定的 `tvcmall-dev/codex-auto-continue` GitHub Releases。默认接收预览版，可切换为仅正式版；只安装较新版本。
- 自动下载本项目的 `CodexAutoContinue.exe`，安装前校验 SHA-256、文件大小和程序版本。
- 打开设置、刷新会话、发送消息、投递通知、测试 Webhook 期间延迟重启。任何仍启用的待续接计划都会延迟安装，包括尚未到执行时间的计划。
- 保存监控与待确认投递状态后再安装，保持窗口或托盘启动方式。网络检查失败时会话监控继续运行。
- 在原目录备份 `CodexAutoContinue.exe.previous`；新进程在 20 秒内未通过启动检查时尝试回退并重启上一版本。失败版本在 24 小时内停止自动升级，可手动重试。
- 自动检查与自动安装均可在设置中关闭。升级只替换 EXE，不请求管理员权限；程序目录需要当前用户可写。

## 下载与构建

[便携 ZIP](https://github.com/tvcmall-dev/codex-auto-continue/releases/download/v0.2.0-preview/CodexAutoContinue-0.2.0-preview-win-x64.zip) · [单独 EXE](https://github.com/tvcmall-dev/codex-auto-continue/releases/download/v0.2.0-preview/CodexAutoContinue.exe) · [SHA-256 清单](https://github.com/tvcmall-dev/codex-auto-continue/releases/download/v0.2.0-preview/SHA256SUMS.txt)

从源码运行 `.\build.ps1` 将执行 Release x64 构建和行为测试，并生成 `0.2.0-preview` 便携目录与 ZIP。构建脚本显式传入版本并核对 EXE `ProductVersion`，确保包版本与程序版本一致。行为测试覆盖版本通道、下载来源与完整性、空闲安装保护、替换和回退。

## 已知限制

已验证真实 Codex 桌面会话读取，当前 Windows Codex 桌面端仍没有暴露已验证的恢复控制端点，尚未验证桌面任务自动恢复成功。`queue --resume` 入队和退出码 0 不代表任务已恢复；程序保持“待确认”，只有实际执行证据才确认恢复，不能保证无人值守续跑。自动升级没有改变这一限制。

完整步骤、升级等待条件及故障恢复见[使用说明](../使用说明.md)。
